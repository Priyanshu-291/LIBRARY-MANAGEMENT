# Library Management System

## Project Overview
The Library Management System is a relational database project developed using MySQL. It stores and manages information about books, authors, publishers, members, book categories, and book transactions. It helps maintain library records and manage book issue and return operations efficiently.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Database Tables
The project contains tables for managing:
- LIBRARY_BOOK
- LIBRARY_AUTHOR
- LIBRARY_PUBLISHER
- LIBRARY_MEMBER
- LIBRARY_CATEGORY
- BOOK_ISSUE
- BOOK_RETURN

## Features
- Store book details and availability.
- Maintain author and publisher information.
- Categorize books by different genres.
- Manage library member information.
- Track book issue and return records.
- Maintain publisher details and locations.
- Retrieve information using SQL JOIN queries.
- Manage and update library records using CRUD operations.

## How to Run
1. Install MySQL Server.
2. Open MySQL Workbench or MySQL Command Line.
3. Open `library_database.sql`.
4. Execute the SQL script.
5. Explore the database using SELECT, JOIN, GROUP BY, and other SQL queries.
